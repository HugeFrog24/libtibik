Тибик (libtibik, либтибик) - удобный мод для Sky: Children of the Light (Sky: Дети света) на Android и Windows. Он берёт на себя рутину: автофарм свечей, сбор бабочек-красителей и телепорт по мирам, а также добавляет внутриигровые элементы управления позицией, энергией, криками и шифрованием чата.

## <img src="assets/android.svg" alt="" height="18"> Быстрый старт - Android

1. Установите Canvas - фреймворк, который загружает моды для Sky на Android:<br>
   https://github.com/skyprotocol/canvas-distribution/releases/latest
2. Скачайте `libtibik.so` из последнего релиза:<br>
   https://github.com/HugeFrog24/libtibik/releases/latest
3. Откройте Canvas.
4. Добавьте `libtibik.so` как мод. Нажмите «Добавить мод».<br>
   _Не открывайте `.so` другими приложениями (блокнот, галерея, архиватор): загрузить его может только Canvas._
5. Запустите Sky оттуда.
6. Тибик появится в палитре модов Canvas, как только Sky запустится.

## <img src="assets/windows.svg" alt="" height="18"> Быстрый старт - Windows

Нужен Sky из Steam. На ПК Sky есть только для Windows.

Есть два пути. Если сомневаетесь, выбирайте первый.

### Простой путь: пусть всё сделает приложение

Tibik Launcher поставит мод за вас, а потом так же уберёт.

1. Откройте последний релиз:<br>
   https://github.com/HugeFrog24/libtibik/releases/latest
2. Скачайте файл, имя которого начинается с `Tibik-Launcher-Setup`.
3. Откройте скачанный файл.<br>
   Windows может показать синее окно **Система Windows защитила ваш компьютер**.
   Нажмите **Подробнее**, затем **Выполнить в любом случае**. Windows пишет это
   потому, что приложение новое. Ничего не сломалось.
4. Оно установится само и откроется. Windows не спросит у вас разрешения.
5. Папку Sky оно найдёт само. Если не нашло, откройте **Settings** и укажите
   папку вручную.
6. Если жёлтая полоса говорит *Sky can't use mods yet*, нажмите **Set up**.
   Прочитайте, что там написано, и нажмите **Set up** ещё раз.
7. На карточке Тибика нажмите **Install**. Прочитайте, что там написано, и
   нажмите **Add**.
8. Запустите Sky из Steam, как обычно.
9. Тибик появится, как только вы окажетесь в игре.

Чтобы убрать его потом, откройте приложение и нажмите **Remove** на карточке
Тибика. Эта инструкция вам больше не понадобится.

### Что меняется на компьютере

Рядом с игрой появляется файл `winhttp.dll`. Windows открывает его при запуске
Sky. Так мод и попадает в игру.

Некоторым антивирусам это не нравится. Ваш может удалить файл или показать
предупреждение. Это антивирус делает свою работу. Это не значит, что что-то
сломалось. Всё можно отменить - смотрите ниже.

На обоих путях это одно и то же. Приложение просто копирует файлы за вас.

<details>
<summary><b>Или вручную</b></summary>

Этот путь для тех, кто не хочет ставить ещё одно приложение.

1. Скачайте `Tibik-Windows.zip` из последнего релиза:<br>
   https://github.com/HugeFrog24/libtibik/releases/latest
2. Закройте Sky, если он открыт.
3. Найдите папку Sky. В Steam нажмите правой кнопкой на **Sky: Children of the
   Light**. Выберите **Управление**, затем **Посмотреть локальные файлы**.
   Откроется папка. `Sky.exe` лежит внутри.
4. Распакуйте скачанный файл.
5. Скопируйте всё из архива в эту папку. Папки внутри оставьте как есть. После
   этого в папке Sky будет вот что:

   ```
   Sky.exe
   winhttp.dll
   html-config.json
   htmodloader\mods\tibik\tibik.dll
   ```

6. Запустите Sky из Steam, как обычно.
7. Тибик появится, как только вы окажетесь в игре.

</details>

### Как выключить обратно

Если вы ставили через приложение, откройте его и нажмите **Remove**. Остальное
оно сделает само.

Вручную уберите только Тибик, удалив одну эту папку:

```
htmodloader\mods\tibik
```

Не удаляйте всю папку `htmodloader`, если только вы правда этого не хотите. Там
лежат и другие моды. И их сохранённые настройки тоже.

`winhttp.dll` и `html-config.json` - это та часть, которая вообще загружает
моды. Ваши другие моды пользуются ими же. Если удалить эти два файла, выключатся
все моды, а не только этот. Делайте так, только если моды вам больше не нужны.
